# AI USAGE REPORT

## 1. AI Tools Used
- ChatGPT: Assistance with project planning, code structure, debugging, testing and documentation.
- Google Gemini API: Used for query-time tax responses and one-time tax rule compilation.

## 2. How AI Was Used
- Assistance in designing the Python project structure.
- Help with writing and reviewing Python functions.
- Help creating unit tests.
- Assistance in designing natural-language prompts.
- Assistance in creating evaluation scripts.
- Gemini was used to generate natural-language tax explanations and responses.
- Gemini was also used to compile tax rules for the compiled-rules approach.

## 3. Human Verification
- Reviewed generated code.
- Executed unit tests for the implemented functions.
- Ran the rules-based and parser evaluation scripts.
- Executed both Gemini evaluation approaches.
- Reviewed generated responses and evaluation results.
- Tax calculations still require independent verification against official tax provisions and trusted calculations.

## 4. Evaluation Summary
- Rules-based evaluator: 200 successful cases.
- Parser evaluator: 50 correct cases.
- Gemini Query-Time: 10 successful responses out of 10.
- Gemini Compiled-Rules: 10 successful responses out of 10.
- Tax accuracy has not yet been independently established.

## 5. Limitations
AI-generated code, rules and explanations may contain errors. API quota limits can affect availability. Incomplete tax provisions can lead to incorrect or incomplete calculations.

## 6. Responsible Usage
AI is used as an assistant during development and as an evaluated component of the LLM approaches. It is not treated as an authoritative source of tax law. Official tax provisions and calculation results require independent verification.
